# 已知限制

本文件区分“工程未实现”“已实现但真实账号未验证”“平台本身不可保证”三类情况。

## 1. 阻塞日常使用的未验证项

### 1.1 Phase 0 未完成

真实抖音测试账号的登录、群列表、实时视频卡片、`event.work`、`work.getAccess()`、历史补拉与失效作品行为尚未在本构建环境验收。

因此：

- `douyin-im` 适配器虽然已按公开 API 接线，但不能宣称对你的账号可用。
- 真实账号的验证码/设备风控可能要求额外步骤。
- 群消息格式可能随桌面客户端更新而变化。
- 在 [acceptance.md](acceptance.md) Phase 0 通过前，不应把本项目作为唯一保存手段。

### 1.2 `douyin-im` 本身的能力边界

上游项目明确说明：

- 部分登录、协议与验证能力只经过离线测试。
- 设备注册、动态证书、Session 绑定等仍可能需要真实账号验收。
- 官方接口与桌面客户端协议都可能变化。
- 本项目锁定 `douyin-im@1.1.0`；升级前必须重新验证登录、收消息和历史补拉。

### 1.3 群消息历史补拉语义

- 补拉基于消息时间游标与分页上限，并非平台保证完整的历史同步协议。
- 短时间离线通过实时重连 + 最近历史窗口覆盖。
- 长离线可能超出平台保留窗口，系统会记录 `gap`，但无法恢复已不在服务端的历史。
- 2 分钟重叠窗口用于降低时钟偏差风险，不能消除平台消息删除、撤回或索引异常造成的缺口。

### 1.4 直链与下载 API

- 签名媒体 URL 只保存在内存中，服务重启后失效。
- 共享作品在直链失效后，会先通过已连接的 `douyin-im` 会话重新获取授权直链（需来源群仍在账号中）；作者关闭官方下载按钮时，会回退到桌面客户端使用的同一播放地址。被平台过滤、已删除或仅音频/图集的作品仍会明确失败。
- `Douyin_TikTok_Download_API` v5 依赖 PostgreSQL、Redis、身份池与 API Key；适配器支持 v5 任务和 v4 响应，但未在真实实例上完成验收。
- 第三方 API 的字段、路径和鉴权方式可能变化。
- yt-dlp 的抖音支持依赖 Cookie/签名，2026 年仍有 403 报告；本项目将 403/需 Cookie 归为不可重试资源失败，不会无限重试。
- HLS/分片直链由 yt-dlp 自行合并；Direct 与 API 适配器优先选择 MP4，不自行合并 HLS。
- 已缓存视频的「平台不可访问」标签是实时查询结果，依赖 `douyin-im` 当前在线；离线或查询失败时显示为未知且不展示标签，不会把查询失败误判为作品失效。该状态不持久化。

## 2. 功能范围限制

| 能力 | 状态 |
|---|---|
| 群内直接发送的视频文件 | 只记录诊断/元数据，首版不下载 |
| 图集、图片、表情 | 不保存，不下载 |
| 直播、回放、评论卡片 | 不下载 |
| 私密作品、需关注/好友权限的作品 | 依赖平台授权；不可访问时明确失败 |
| 作者主页批量抓取 | 明确不做 |
| AI 摘要、标签、内容理解 | 不做 |
| 自动回复、自动审批入群 | 不做 |
| 多账号 | 不支持；当前单账号 |
| 多用户 / 权限分级 | 不支持；单个管理员 |
| 多实例共享同一数据目录 | 不支持；SQLite 单写者 |
| 云端同步 | 不做 |
| 自动绕过已删除作品限制 | 不做；本地缓存是唯一保障 |
| 播放列表、连续播放 | 未实现 |
| 未解析卡片重处理 | 保留元数据，但未提供一键重解析工作流 |
| 字幕、转码、剪辑 | 未实现 |
| 移动端原生 App / PWA | 只有响应式 Web；PWA manifest 与离线缓存未实现 |

## 3. 平台与合规限制

- 官方开放平台的群消息 Webhook 仅覆盖粉丝群，且视频分享消息不提供具体媒体 URL，不能替代本项目的主方案。
- 抖音可能调整群消息结构、作品卡片字段、媒体权限、签名或风控。
- 作者删除、设为私密、地域限制、账号封禁都可能导致原作品不可访问。**只有失效前已完整缓存才能回看。**
- 本项目不保证恢复任何未缓存内容。
- 请仅缓存你已获授权访问的群聊；遵守平台条款、版权与当地法律。

## 4. 认证与验证限制

- 登录主路径是二维码；短信/密码登录分支未在本项目 UI 中实现。
- 二次验证页由 SDK 启在 `127.0.0.1`，通过 Cloudflare 远程访问时不能直接在手机上打开。需要 SSH 端口转发或在 Mac mini 本机完成。
- 管理会话固定为单管理员密码，没有用户名、找回密码邮件或 MFA。
- 重置密码只能在本机执行 `pnpm reset-password`。
- 管理登录限流是单进程内存实现，重启后清零；不防分布式暴力破解。公网入口必须叠加 Cloudflare Access。

## 5. 部署限制

- 原生 macOS 部署优先；Docker 路径未完成真实账号验收。
- LaunchAgent 需要用户登录后运行。LaunchDaemon（无人登录自启）未验证 IM/浏览器/文件权限兼容性。
- Playwright 备用方案需要持久化浏览器 profile，可能依赖桌面图形环境；headless 登录/选择器未验证。
- Cloudflare Tunnel 是外部依赖；Tunnel/Access 配置错误会直接导致不可用或暴露风险。
- 没有内置 TLS。HTTPS 必须由 Cloudflare 或本地反代提供。
- 没有自动更新。升级第三方动态协议实现需要人工验收。

## 6. 数据限制

- 备份数据库不等于备份视频；Time Machine/rsync 需单独配置。
- 删除媒体后如果原作品已不可访问，无法恢复。
- 同一作品以不同作品 ID 重新上传时可能被视为新视频；只有无作品 ID 的聊天视频才使用 SHA-256 辅助合并。
- 视频文件路径被外部移动后，系统会标记 `FILE_MISSING`，不会自动猜测新路径。
- SQLite 适合单实例单用户；不要多进程同时写同一个数据库。
- 媒体文件大小按实际磁盘计算；清理使用数据库记录与文件扫描，极端并发下仍有短暂不一致窗口。
- 封面抽帧失败或远程封面不可下载时，视频仍可用，但没有封面。
